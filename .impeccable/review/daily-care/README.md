# Daily-care composition review

Synthetic account data rendered from the real React Native components through React Native Web. Captures cover narrow and tablet water layouts, medicine, cycle, Health, Settings and the 320px Activity screen. These checks verify composition and wrapping, not native interactions, screen-reader focus, notification delivery, motion sensors or audio.

The Activity capture shows separate food and active-calorie targets. Phone-step controls are available before the metric rows. No source readings are combined.
