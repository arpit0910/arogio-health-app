# Consistent care and clear destinations

Mode: Operate. The user approved Home's emerald/mint identity for the whole application on 4 November 2026. Extend that established identity, retain Arogio's logo and daily-care behavior, and remove repeated health connection prompts. No replacement visual world or new imagery system is introduced.

THESIS: Returning users should reach a daily action, a trend or a helpful discovery without passing through another connection setup.

WORLD: Shared Inter typography, the existing emerald/light-mint palettes, pastel category cues, 16-unit page gutters, tonal summaries and grouped navigation rows. Shared PageIntro establishes one purpose per screen. Forms retain native keyboard, enlarged-text and permission behavior.

PATH: Home is today's actions and a source-labelled activity summary. Health contains routines, personal care and real recorded trends. Explore contains articles, meditation/breathing and practical local help. Meditation contains written sessions and the supplied affirmation videos. Settings is the connection-management destination; Profile and the sidebar lead to Settings rather than duplicating its controls. Manual phone access setup contains motion/location rather than another health-source picker.

FINISH: Source checks, native module compilation, rendered composition checks and the local build are recorded in docs/app-refresh.md. Physical Pebble Halo and native accessibility acceptance require a connected phone; source tests are not evidence that the wearable exports correct data.
