# Reminder sounds and deferred profile setup

Notification channels now explicitly configure sound: system default for medicine/cycle and the bundled water-drop file for water. New channels use HIGH importance. Existing Android channel choices remain under the user's control; re-registering a channel does not repair a channel the OS has already muted. The notification config sets the default Android remote-notification channel to wellness. iOS permission requests explicitly include sound.

Settings > Notifications checks sound and importance for both Android channels (and sound permission on iOS), explains silent/blocked channels, opens each channel's device settings, and can schedule a real three-second test through either channel. Tests do not alter saved tracker reminders or repeatedly ask for permission. Device volume, silent mode and Do Not Disturb still control audible delivery. Physical audio is not verified by mocked tests or composition previews. The native default-channel configuration requires a rebuilt app.

Profile setup includes Skip for now on every step. It saves setupDeferred=true in the account's existing profile JSON. Entry, authenticated navigation, app header and the optional access gate accept either real completion or explicit deferral. Skipping does not fabricate personal details, overwrite saved progress, or set profileCompletedAt. Profile includes Finish profile setup for incomplete accounts; returning resumes from saved details. Actual completion retains validation and clears deferral. No database migration is needed. Deploy the updated backend with the app so it accepts and persists the deferral field.
