# Water reminder sound

`assets/sounds/water_drop.wav` is an original synthesized droplet cue generated by `scripts/generate-water-sound.py` (PCM16 mono, 44.1 kHz). The Expo notifications plugin bundles it into native builds.

Only water reminders use this cue. Android uses stable channel `water-reminders-v1`; other reminders retain their existing sound. System volume, silent mode, Do Not Disturb and channel preferences still apply. The Water screen opens device reminder settings. Existing Arogio water schedules are replaced when rescheduled, without removing unrelated notifications.

Automated verification covers WAV/config validity, Android and iOS notification payloads, permission failures and settings links. The Android raw resource was verified against the source asset. Actual audibility and device delivery require a fresh native installation and physical-device acceptance.
